# Research scope and interpretation

## Results represented by the package

The source construction supplies a CSS2 representation with contact-preserving
distribution calculus, canonical boundary conversion, ordered matching-log
recurrences, and one unexpanded spectral-canonical realization. Its analytic
arguments state the input domain, infrared completion, endpoint composition,
logarithmic-degree counting, and a convergent momentum-resolvent evaluator.

The numerical package makes the accompanying structural checks reproducible.
It uses fixed-order symbolic identities, rational formal fixtures, a lower-order
demonstration, sourced physical N³LL evolution coefficients, and finite-grid
operator comparisons, each labeled at the point of use. A model-agnostic
nonperturbative interface accommodates admitted localized inputs.

## Conditions carried by the analytic construction

The core class is scalar/radial, fixed flavor, asymptotically free, and equipped
with the declared endpoint-independent infrared scale completion. Endpoint
operators use the common logarithmically weighted domain; complete canonical legs
use the bounded symbol class. Longitudinal convolutions and optional
nonperturbative CS factors must satisfy the stated domain/growth conditions.

Conventional N³LL evolution uses cusp/beta through four loops and noncusp and
canonical CS boundary through three loops. Third-order hard and canonical matching
boundaries supply the prime. The retained all-order tower argument is analytical;
finite coefficient-degree tests provide regression evidence for its recurrence.

## Numerical milestones tracked separately

| Milestone | Evidence in this package |
|---|---|
| Scientific/component tests | Fresh per-suite logs and structured outputs |
| Lower-order unexpanded demonstration | Explicit QCD fixture and endpoint/grid checks |
| Physical N³LL evolution | Sourced 4/4/3/3-loop input, independent formula comparison, RG and operator checks |
| Physical N³LL′ spectrum | Requires three-loop hard/matching boundaries and independent observable benchmarks |
| Continuum/grid error certificate | Requires box/spacing control beyond same-grid tests |
| Full-spectrum prediction | Requires process-specific W+Y and power-correction treatment |
| Statistical TMD extraction | Requires data, model/closure, and uncertainty analyses |

The runner reports this scope alongside success results. It does not infer a
physical label from a filename, a document section, a test count, or a Boolean
coefficient metadata field.

## Reporting results

State applicability conditions alongside each numerical result. Cite the exact
code commit and input hashes used for a run. Source imports, same-grid comparisons,
and observable predictions require their own evidence and scope.
